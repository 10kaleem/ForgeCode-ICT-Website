# ForgeCode - Saeed Book Bank Website Redesign

This is the GitHub repository for the ICT Website Project (CSC-114, Fall 2026, Bahria University Islamabad).

Our team, ForgeCode, is redesigning the website of [Saeed Book Bank](http://saeedbookbank.com/), an online book store. The current site is old and hard to use. Our version will be a clean, simple, mobile-friendly site with six pages.

## Project Status

**Deliverable 1 (Planning and Analysis): done.** This includes the problem statement, requirements, site map and wireframes. The planning report is written in LaTeX and is kept separately.

Deliverable 2 (design and front-end pages) is next.

## Planned Pages

| Page | File | What it has |
| --- | --- | --- |
| Home | index.html | Banner, subjects, new arrivals |
| Books | books.html | Book cards, subject filter, search, best sellers |
| About | about.html | Short text about the store |
| Contact | contact.html | Contact form and store details |
| Suggestions | suggestions.html | Form for book or subject suggestions |
| FAQ | faq.html | Questions that open and close |

## Wireframes

The wireframes are in [`docs/wireframes/`](docs/wireframes/):

- `wireframe-0-sitemap.png`: site map of the six pages
- `wireframe-1-home.png` to `wireframe-6-faq.png`: one drawing for each page, on a desktop screen
- `wireframe-7-mobile.png`: the Home page on a phone, with the menu closed and open

These are rough layouts only. The final colours, text and images will be added in Deliverable 2.
